# DAA Repository — Documentation & Output Reference Pack

This folder is arranged unit-wise for the repository's seven DAA units.

## Contents in each unit
- `Algorithm-Documentation.md`: algorithm concept, pseudocode, flowchart (Mermaid), and best/average/worst time plus auxiliary-space complexity.
- `Output-Screenshots/`: one VS Code-layout screenshot per algorithm: source editor on top and the selected Output panel below.

## Important accuracy note
The public GitHub repository was visible, but its full source tree could not be retrieved in this session. Therefore, the output images are clearly labelled **representative output references**, not genuine screenshots captured by compiling and running every exact repository `.java` file. The examples and algorithm inventory are based on the repository's visible README and the unit topics discussed in this chat. Please compare with your actual class names, sample inputs, and output before submitting as execution proof.

## Suggested way to create genuine screenshots
1. Open each `.java` file in VS Code.
2. Compile and run it in the integrated terminal (or Output panel if using Code Runner).
3. Capture the complete output with `Win + Shift + S`.
4. Replace the corresponding reference image in `Output-Screenshots`.
5. Keep source filename and input visible in each capture.

## Flowcharts
The flowcharts are embedded as Mermaid diagrams in the Markdown files. They render in GitHub when Mermaid support is available, or can be exported through a Mermaid-compatible editor.
