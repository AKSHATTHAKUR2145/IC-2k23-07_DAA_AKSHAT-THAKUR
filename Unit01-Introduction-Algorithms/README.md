# Unit 01 – Introduction to Algorithms

This folder contains the **Unit 01 – Introduction to Algorithms** lab work for the Design and Analysis of Algorithms (DAA) course.

## Topics Covered

- Introduction to Algorithms
- Characteristics of an Algorithm
- Algorithm Design and Analysis
- Time Complexity
- Space Complexity
- Asymptotic Notations
  - Big O – `O`
  - Omega – `Ω`
  - Theta – `Θ`
- Best Case, Average Case, and Worst Case Analysis
- Basic Algorithmic Problem Solving

## Implementation

All programs in this unit are implemented in **Java** with a focus on:

- Clean and readable code
- Reusable methods
- Proper comments and structure
- Understanding algorithm logic and complexity

## Purpose

The purpose of this unit is to build a strong foundation in **algorithm design, implementation, and complexity analysis**, which will be used in the upcoming DAA units.
